# 便携版 ZIP 的受管文件清单（issue #28，供 #29 的自更新消费）。
#
# 每行一个仓库相对路径，`#` 起头的行与空行忽略。**不要写通配符**：
# 这份清单是"这个 release 拥有哪些文件"的权威答案，#29 只会替换/删除
# 这里列出的文件，没列出来的用户文件一律不动。
#
# 除这些文件之外，打包器还会放进两样东西（都不是本清单的行）：
#   python/                精简 CPython 运行时，见 release/portable_runtime.py；
#                          release_tools.py portable --runtime 强制要求它存在，
#                          缺了它就不是便携包而是源码包了
#   release-manifest.json  包内标记文件，写死版本、root、受管文件与受保护目录
# 整包放在 root 目录（默认 codearts-hub/）下，与既有便携包一致。
#
# 刻意不包含：
#   accounts/  usage/      —— 用户数据，属于受保护路径，永不作为替换目标
#                            （程序启动时自己 os.makedirs，不需要占位文件）
#   Dockerfile / docker-compose* / quick-deploy.sh —— Docker 部署路径，不进便携包
#   tests/  .github/  release/  wrt/  scripts/ —— 开发与发布工具，不进便携包
#
# tests/_test_release_assets.py 会断言：仓库里每个 ca_*.py 都在这份清单里
# （新增模块忘了登记会直接红），且清单里的路径都存在。
